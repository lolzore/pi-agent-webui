Your picture is redrawn at the size below and written out as a PNG, because a browser silently ignores a CSS cursor that is too large or in a format it will not use as one. The hotspot is the pixel that sits on the real pointer tip — usually the top-left corner (0, 0). Everything gets the picture, including text fields; the browser's own text caret is kept.
